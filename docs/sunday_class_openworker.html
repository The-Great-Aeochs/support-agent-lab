One coding task, two agent runtimes

Follow one user message from entry point to model request, tool result, and the next session. Teach OpenWorker first, then run the same walkthrough in Hermes Agent.

The test command returns thousands of lines. The model proposes opening a PR.

  1. Mark the source of the repo instructions, the first failure, and a durable user preference.
  2. Circle the call ID that ties the test command to its result. Pick one fact the compactor should keep.

Reveal a reference answer

Project instructions shape the request. The original failure belongs in the transcript or tool artifact. A durable preference can go in curated memory.
